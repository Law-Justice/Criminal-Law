# Criminal Law: The Case File

A live, Pear Deck-style classroom game that combines the "Criminal Law" and "People Involved in
Criminal Law" decks and adds Colorado details, diagrams, and scenario-based questions.
Students move a marker along the scale of proof, from a hunch to proof beyond a reasonable doubt. Multiple-choice questions are scenario-based, with plausible wrong answers and many two-part answers.

## What's inside (105 slides, six acts)
- Act I The Crime: criminal vs. civil, standards of proof, elements, mental states, felony/misdemeanor, Colorado levels, theft family, white-collar crimes
- Act II The Accused: constitutional rights, Miranda, double jeopardy, defenses, pleas
- Act III The Players: snowglobe, courtroom map, jury, witnesses, prosecutors, defense, victims
- Act IV The Courtroom: case process, pre-trial, trial procedure, burden of proof, verdict, sentencing, appeal
- Act V The Deal: plea bargaining
- Act VI The Verdict: six jury votes, plus a key-terms recap

## Publish on GitHub Pages
1. Create a public repository (for example `criminal-law`) and upload `index.html` to the top folder.
2. Settings > Pages > Source: **Deploy from a branch** > Branch: `main`, folder `/ (root)` > Save.
3. After a minute or two your site appears at `https://YOUR-USERNAME.github.io/REPO-NAME/`.

## Run a class
1. Open the page and choose **I'm the teacher**. You get a 4-letter class code.
2. Students open the same address (or use **Copy student link**), enter the code, and pick a call sign.
3. Use the arrow keys, Next/Prev, or the **Jump to...** menu to move between acts. On question slides,
   press **Reveal answer**. Each act is a natural stopping point for a class period.
4. **Case Board** shows each student's marker on the scale of proof. Keep the teacher tab open.

## Editing the deck
Use the Case File Deck Editor to change questions and slides, then export a new `index.html`.

## If students on another network (Wi-Fi vs. wired) can't connect
Create a free account at https://www.metered.ca/tools/openrelay/ , make an app, and enter the app name and
API key in the editor's relay fields before exporting (or edit `TURN_RELAY` near the top of the script).
The teacher's title slide shows **Relay: ON** when it is working.

## Notes
- Colorado details (offense classes, penalty ranges, juror counts) reflect state law as of late 2026.
  Check current statutes before relying on exact numbers.
- Answer keys are in the page source, so a student who views source could find them.
- Call signs and written responses are student-typed and are not moderated.
- "Try it solo" runs the whole deck on one device with no network.
